# NAKAMA · Juego de rol

Versión estática preparada para GitHub Pages a partir del fichero MHTML original.

## Publicación en GitHub Pages

1. Sube `index.html` y la carpeta `assets/` a un repositorio.
2. En **Settings → Pages**, selecciona la rama que contiene estos archivos y la carpeta raíz (`/`).
3. Guarda la configuración y abre la URL de GitHub Pages.

La navegación interna por las secciones se conserva. El MHTML proporcionado contiene la página renderizada y no incluye el JavaScript original de los controles interactivos, por lo que esos controles no se han inventado ni reimplementado.
